# Sync it: Android downloads

Watch Netflix or JioHotstar together, each on your own phone, in sync.

**Download:** [sync-it.apk](https://github.com/aritraroy02/sync-it-releases/raw/main/sync-it.apk) (Android 8.0+)

Open the file to install it. If Android asks, allow your browser to install apps.
Invite links (`https://syncit-watchparty.web.app/join/CODE`) open the room straight in the app.
